# Security policy

Pith Desk is an experimental, single-user local desktop application. Its current
capabilities and limits are described in the [README](README.md), with the
threat model and data handling in [docs/SECURITY.md](docs/SECURITY.md).

## Supported version

Security fixes are applied to the latest `main` branch. Older snapshots and
unpublished local builds do not have a separate maintenance policy.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** action in the repository's
[Security tab](https://github.com/minifish-org/pith-desk/security/advisories/new)
to contact the maintainers privately. Include the affected commit, operating
system, steps to reproduce, impact, and a minimal example using disposable
files. Do not include real model keys, MCP tokens, private conversations, or
sensitive workspace contents.

Please keep exploit details out of public issues until the report has been
reviewed and a fix is available. Ordinary bugs and feature requests can use
public issues. There is no paid bug bounty or guaranteed response time.
